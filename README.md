# dev-learning

A personal repository for learning, practicing, and documenting wireless communication concepts.

The repository contains hands-on exercises, notes, experiments, and small projects developed while learning and improving software development and wireless communication skills.

### Wireless Communication

Wireless communication and 5G NR PHY concepts are implemented and explored using Python.

The Python implementations and test cases can be found under:

```text
wireless/testcases/
```

The programs in this directory can be run directly using Python.

## Getting Started

### 1. Clone the Repository

Clone the repository using Git:

```bash
git clone https://github.com/chandan-bangalore/dev-learning.git
cd dev-learning
```

### 2. Installation

Python-based examples can be run using Python 3.

It is recommended to use a Python virtual environment:

```bash
python3 -m venv venv
source venv/bin/activate
```

Upgrade pip:

```bash
python3 -m pip install --upgrade pip
```

Install the required Python packages:

```bash
pip install numpy pandas matplotlib
```

Additional dependencies may be required for specific examples.

### Running Wireless Communication Examples

Navigate to the wireless testcases directory:

```bash
cd wireless/testcases
```

Run a Python testcase, for example:

```bash
python3 main.py
```
